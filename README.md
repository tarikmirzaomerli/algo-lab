# Algo Lab

Algo Lab, temel sıralma (Sorting), arama (Searching) ve graf (Graph) algoritmalarını adım adım ve etkileşimli olarak görselleştiren bir web uygulamasıdır.

## 🚀 Teknolojiler

- **Core & UI:** React 19, TypeScript, Vite
- **İkonlar:** Lucide React
- **Test:** Vitest, Testing Library

## 🛠️ Kurulum ve Çalıştırma

Bağımlılıkları yüklemek ve geliştirici sunucusunu başlatmak için:

```bash
npm install
npm run dev
```

## 🏗️ Build (Canlıya Hazırlama)

Production build almak için:

```bash
npm run build
```

Derlenen çıktılar `dist/` klasörüne oluşturulur.

## 🧪 Testleri Çalıştırma

Birim ve entegrasyon testlerini çalıştırmak için:

```bash
npx vitest run
```
